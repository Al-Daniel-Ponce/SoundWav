Explain It

Short answers

1 How does your app change a sound wave into binary? Name the three steps.

My app changes sound into binary in three steps: sampling (measure the wave height at even times over one period), quantization (round each height to the nearest whole level from 0 to 2^bits - 1), and encoding (write each level in binary with leading zeros so every value has exactly bits digits).

2 Run Test A again with 2 bits, then 6 bits. Which gives more detail about the wave, and why?

6 bits gives more detail because it has 64 levels while 2 bits has only 4 levels, so the steps are smaller and each binary value stays closer to the real wave height.

3 Which test has the longest wavelength? How is wavelength connected to frequency?

Test B has the longest wavelength at 1.72 m. Wavelength equals 343 / frequency, so they are inversely related: a lower frequency gives a longer wavelength.

4 What was the hardest stage to build, and how did you fix it?

The hardest stage was binary encoding, because the levels rounded wrong and the binary lost its leading zeros. I fixed it by testing with frequency 1000, amplitude 1, samples 4, bits 2 until it matched 10 11 10 00, using Math.round for rounding up and padStart for the leading zeros.
